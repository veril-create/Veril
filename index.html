📲 Pasang di Layar Utama HP

  1. Android (Chrome): Ketuk ikon titik tiga ⋮ di pojok kanan atas browser, lalu pilih Tambahkan ke layar utama (Add to Home screen) atau Instal aplikasi.

  3. Tips File Lokal: Jika file dibuka dari folder Downloads dan menu "Tambahkan ke layar utama" tidak muncul, buka lewat Chrome atau unggah ke hosting gratis (seperti GitHub Pages / Netlify Drop) agar muncul ikon aplikasi penuh di layar utama.
